# educateU Applicant Hub: clickable prototype

Vite + React + TypeScript + Tailwind v4. Brand tokens from the educateU brand guide (Manrope, ink and mint, pill controls, signature easing).

    npm install
    npm run dev      # http://localhost:5173

State is mock data saved in localStorage. Open "Prototype controls" in the footer to reset, load a scenario
(default, three offers waiting, first visit) or simulate admissions team actions (make an offer, conditions met or not met).
Treat "today" as 7 Oct 2026.
